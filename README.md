# configuration_management_kuznetsov_s_IKBO-23-25
Репозиторий с практическими заданиями по дисциплине "Конфигурационное управление". 
Работу выполнил студент группы ИКБО-23-25 Кузнецов С.

## Вариант 11. Эмулятор оболочки

Этап 1: консольный прототип с приглашением demo:/>.

Поддерживаются:
- ls и cd — заглушки, выводящие имя команды и аргументы;
- exit — завершение работы;
- сообщения об неизвестной команде и неверном количестве аргументов;
- пропуск пустых строк.

Команды ls и cd принимают не более одного аргумента.
Команда exit не принимает аргументы.
Ввод разделяется по пробельным символам; кавычки не обрабатываются.

## Запуск

Требуется Python 3.13. Дополнительные библиотеки не нужны.
Сборка не требуется. Команды выполняются из корня репозитория.

```powershell
python src/main.py
./run.bat
```

## Проверки парсера

```powershell
python -m tests.test_parser
```

При успешном выполнении выводится: «Все проверки пройдены».

## Этап 2. Конфигурация

Параметры запуска:
- --vfs: путь к VFS, по умолчанию vfs.csv;
- --log: путь к CSV-журналу, по умолчанию commands.csv;
- --script: путь к необязательному стартовому скрипту.

При запуске выводятся значения всех настроек.
Загрузка VFS будет реализована на этапе 3.

Все непустые команды записываются в CSV-журнал.
Каждая запись содержит имя пользователя, дату и время, команду.
Существующие записи сохраняются.

Стартовый скрипт выполняется построчно с отображением ввода
и вывода. Ошибочные команды не прерывают выполнение.
Корректная команда exit завершает эмулятор.

Функции:
- parse_command: разделяет ввод на команду и аргументы;
- parse_args: получает параметры запуска;
- log_command: добавляет событие в CSV-журнал;
- execute_command: обрабатывает команду;
- run_script: выполняет команды стартового скрипта;
- main: запускает скрипт и интерактивный диалог.

Пример запуска:

```powershell
.\run.bat --vfs demo.csv --log events.csv --script startup.txt
```

Проверка параметров запуска:

```powershell
.\test_config_default.bat
.\test_config_custom.bat
```
## Этап 3. Виртуальная файловая система

VFS загружается из CSV со столбцами path,type,data.
Пути абсолютные, разделитель — /.
Тип dir обозначает папку, file — файл.
Содержимое файлов хранится в Base64.

В памяти VFS представлена словарём:
ключ — виртуальный путь;
значение — None для папки или байты для файла.

Загрузчик проверяет формат, типы, уникальность путей
и наличие родительских папок.

Команда vfs-init без аргументов сбрасывает VFS
до одной корневой папки и перезаписывает исходный CSV.
Это служебная команда, изменяющая физическое представление.

Функции модуля src.vfs:
- load_vfs: загрузка CSV в память;
- validate_tree: проверка корня и родительских папок;
- reset_vfs: сброс VFS в памяти и на диске.

Запуск:

```powershell
python -m src.main --vfs examples/deep.csv
```

Проверки:

```powershell
python -m unittest discover -s tests -v
.\test_vfs_minimal.bat
.\test_vfs_variants.bat
```

Скрипты проверки работают с копиями примеров.
Сборка проекта не требуется.

## Этап 4. Основные команды

- ls [путь]: содержимое папки или имя выбранного файла.
  Папки выводятся с завершающим /.
- cd [путь]: переход в виртуальную папку.
  Без аргументов — переход в корень.
- history: непустые команды текущего сеанса с номерами.
  Включает ошибочные команды и сам вызов history.
- du [путь]: объём содержимого в байтах.
  Для папки выводит размеры вложенных папок и общий размер.
  Без аргумента использует текущую папку.

ls, cd и du принимают не более одного пути.
history не принимает аргументы.
Флаги команд не поддерживаются.

Поддерживаются абсолютные и относительные пути, . и .. .
Все операции выполняются над VFS в памяти.

Функции модуля src.commands:
- resolve_path: проверка и разрешение виртуального пути;
- command_ls: вывод содержимого;
- command_cd: смена текущей папки;
- command_history: вывод истории;
- subtree_size: подсчёт объёма файлов;
- command_du: вывод размеров.

Проверка команд и обработки ошибок:

```powershell
python -m src.main --vfs examples/deep.csv --script examples/stage4.txt
python -m unittest discover -s tests -v
```
## Этап 5. Удаление

- rm путь: удаление одного файла;
- rmdir путь: удаление одной пустой папки.

Обе команды требуют ровно один аргумент.
Флаги и рекурсивное удаление не поддерживаются.
Нельзя удалить корень VFS или текущую папку.
Ошибочные команды не прерывают работу эмулятора.

Функции command_rm и command_rmdir находятся в src.commands.
Они удаляют записи только из словаря в памяти.
Исходный CSV не изменяется.
При повторном запуске исходные файлы и папки восстанавливаются.

Проверка:

```powershell
python -m src.main --vfs examples/deep.csv --script examples/stage5.txt
python -m unittest discover -s tests -v
```
