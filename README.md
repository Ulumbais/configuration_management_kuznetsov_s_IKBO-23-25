# configuration_management_kuznetsov_s_IKBO-23-25
Репозиторий с практическими заданиями по дисциплине "Конфигурационное управление". 
Работу выполнил студент группы ИКБО-23-25 Кузнецов С.

## Вариант 11. Эмулятор оболочки

Этап 1: консольный прототип с приглашением demo:/>.

Поддерживаются:
- ls и cd — заглушки, выводящие имя команды и аргументы;
- exit — завершение работы;
- сообщения об неизвестной команде и неверном количестве аргументов;
- пропуск пустых строк.

Команды ls и cd принимают не более одного аргумента.
Команда exit не принимает аргументы.
Ввод разделяется по пробельным символам; кавычки не обрабатываются.

## Запуск

Требуется Python 3.13. Дополнительные библиотеки не нужны.
Сборка не требуется. Команды выполняются из корня репозитория.

```powershell
python src/main.py
./run.bat
```

## Проверки парсера

```powershell
python -m tests.test_parser
```

При успешном выполнении выводится: «Все проверки пройдены».

## Настройки

На первом этапе имя VFS задано переменной vfs_name в src/main.py.
Загрузка VFS и параметры командной строки будут добавлены позже.

```text

demo:/> ls docs

demo:/> ls docs extra
Ошибка: слишком много аргументов

Ошибка: слишком много аргументов

Ошибка: неизвестная команда

Ошибка: exit не принимает аргументы
demo:/>
demo:/> cd       docs
```
